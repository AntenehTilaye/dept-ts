# Design documents

Read in order. `00-plan.md` is the approved implementation plan (decisions, tech stack, phase table
and verification). `01`–`02` are the stack-independent architecture blueprint (entities, services,
workflows, engines, coverage of the 34 requirement sections). `03`–`05` are the concrete design on
the fixed stack (feature builder and generic runtime, Prisma schema with tenancy and auth, repository
layout with Docker, worker and testing strategy). `06`–`07` are the long-form phase specifications;
where they differ from `00-plan.md`, the plan wins.
